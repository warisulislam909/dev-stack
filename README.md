# Dev Stack

A pixel-inspired recreation of the supplied Dev Stack landing page using:

- React + TypeScript
- Tailwind CSS
- DaisyUI
- React-Toastify
- JSON technology data
- Vite

## Run

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

The page is responsive and the technology cards, stack panel, remove buttons, navigation, and auth buttons are interactive. Toast notifications are wired with React-Toastify.


1 ans= We can deploy the site on platforms like Vercel, Netlify, or GitHub Pages.
2 ans= No, TypeScript is not mandatory. You can use JavaScript or TypeScript depending on the project requirements.
3 ans= Yes, you can change them.
4 ans= We can get technology logos/icons from Simple Icons, Devicon, or Font Awesome.
